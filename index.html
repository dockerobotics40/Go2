Ejemplos y demostraciones para el robot UNITREE Go2

Bienvenido al repositorio de Robotics 4.0 para el robot UNITREE Go2. Aquí encontrarás guías de instalación, configuración y ejemplos prácticos usando el SDK oficial.

Autores: Sofia Castaño, Samuel Romero, Adrian Chavarro, Mario Arbulu

Comienza con la instalación de los componentes esenciales:

Instalar unitree_sdk2 Instalar unitree_ros Instalar unitree_sdk2_python
